# Ressources Claude Code

## Connaissances

- [How Claude Code works (doc officielle)](https://code.claude.com/docs/en/how-claude-code-works)
  La boucle agentique, les outils, les modes de permission, les retours en arrière. À lire en premier.
- [Overview (doc officielle)](https://code.claude.com/docs/en/overview)
  Ce qu'est Claude Code et sur quels supports il tourne. Pour la vue d'ensemble.
- [Desktop (doc officielle)](https://code.claude.com/docs/en/desktop)
  L'application bureau : choix du dossier, local ou cloud, modes, vue des modifications. Votre support principal.
- [Memory / CLAUDE.md (doc officielle)](https://code.claude.com/docs/en/memory)
  Où placer les fichiers CLAUDE.md, quand ils sont lus, quoi y mettre. Pour écrire vos briefs permanents.
- [Checkpointing (doc officielle)](https://code.claude.com/docs/en/checkpointing)
  Revenir en arrière après une modification. Non encore lu en détail.
- [Cours Claude Code in Action (Anthropic Academy)](https://anthropic.skilljar.com/claude-code-in-action)
  Cours officiel gratuit (inscription requise). Orienté développeurs : à garder pour plus tard.

## Sagesse (communautés)

- [Communauté Claude (page officielle)](https://claude.com/fr/community)
  Point d'entrée officiel vers le Discord et les événements. Pour poser des questions et voir des cas réels.
