Aide-mémoire Claude Code

L'essentiel pour l'application bureau, à imprimer ou garder ouvert.

Démarrer une session

  1. Application Claude, onglet Code.
  2. Environnement Local (vos fichiers) ou Cloud (continue même app fermée).
  3. Choisir le dossier de projet : Claude n'accède qu'à ce dossier sans permission.
  4. Choisir le mode de permission, puis écrire la demande.

Source : Desktop

Modes de permission

ModeCe qu'il faitQuand l'utiliser
ManualDemande avant chaque modification ou commande.Débuter, documents importants.
Accept editsModifie les fichiers sans demander ; demande pour les autres commandes.Travail en confiance sur un dossier sauvegardé.
PlanExplore et propose un plan, sans rien modifier.Avant une tâche longue ou floue.
AutoUn contrôle automatique bloque les actions risquées au lieu de demander.Plus tard, quand vous connaissez l'outil.
BypassAucune demande. À réserver aux environnements isolés.Jamais sur votre Mac.

Changer de mode : sélecteur sous la zone de saisie, ou Cmd+Shift+M.

Sources : Desktop, How Claude Code works

CLAUDE.md, le brief permanent

EmplacementPortée
dossier/CLAUDE.mdCe projet. Lu au début de chaque session.
~/.claude/CLAUDE.mdTous vos projets (vos règles personnelles).
dossier/CLAUDE.local.mdCe projet, pour vous seul, non partagé.
  • Moins de 200 lignes. Règles concrètes et vérifiables.
  • C'est du contexte, pas une obligation : toujours vérifier le résultat.
  • Jamais de mots de passe ni de données client sensibles.

Source : Memory

Réflexes de sécurité

  • Échap : arrêter Claude immédiatement.
  • « Annule ta dernière modification » : Claude garde une copie de chaque fichier avant de le modifier.
  • Ce qui part hors de votre Mac (e-mail envoyé, site publié) ne s'annule pas.
